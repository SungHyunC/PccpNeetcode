# 15. 2차원 DP (2-D Dynamic Programming)

> 상태를 두 개의 변수(격자 좌표, 두 문자열의 위치, 물건 × 용량, 날짜 × 상태)로 정의하고 표를 채우는 DP 입니다.

## 이런 문제에서 떠올리세요

- **격자(grid)** 에서 오른쪽/아래로만 이동하며 경로 수·최소 비용·최대 합을 묻는 문제 → 격자 DP
- **문자열 두 개** 를 비교: 공통 부분 수열, 편집 거리, 한 문자열이 다른 문자열을 포함하는 방법 수 → `dp[i][j]` = 두 접두사
- **무게/용량 제한** 아래 가치 최대화, "합이 정확히 S 가 되는 부분집합" → 배낭(knapsack) 계열
- **오늘 할 수 있는 행동이 어제의 상태에 따라 달라짐** (보유 중/쿨다운/거래 횟수) → 상태 기계(state machine) DP
- **삼각형/피라미드** 에서 위 → 아래로 내려가며 합 최대화 → 삼각형 DP (프로그래머스 '정수 삼각형')
- **사이클 없는 이동**(더 큰 값으로만 이동 등) + 칸마다 최장/최단 → DFS + 메모 (DAG 위의 DP)
- 결과를 **1,000,000,007 로 나눈 나머지** 로 내라는 문구 → 경우의 수 DP 일 확률이 매우 높음
- 입력 크기 힌트
  - 두 문자열 길이 ≤ 1,000~5,000 → O(n × m) 표 가능
  - 격자 ≤ 100 × 100 ~ 1,000 × 1,000 → O(R × C)
  - n × W ≤ 10^7 정도 → 배낭 O(n × W)
  - 구간 DP 는 보통 n ≤ 500 (O(n^3))

## 핵심 개념

### 2차원 표는 "어느 칸을 보고 채우는가" 가 전부

```
            j-1        j
         ┌────────┬────────┐
   i-1   │   ↖    │   ↑    │     dp[i][j] 는 보통 이 세 칸(↖, ↑, ←)에서 만들어집니다.
         ├────────┼────────┤     → 행 우선(위 → 아래, 왼 → 오)으로 채우면 항상 준비되어 있음
   i     │   ←    │dp[i][j]│
         └────────┴────────┘
```

### 격자 DP — 등굣길 유형 (웅덩이 = 0)

```
dp[r][c] = 0                          (웅덩이)
         = dp[r-1][c] + dp[r][c-1]    (그 외, % 1,000,000,007)

3 × 4 격자, 웅덩이 (2, 2)                 (패딩 0행·0열을 두면 경계 처리 불필요)
        c=1  c=2  c=3  c=4
  r=1    1    1    1    1
  r=2    1    0    1    2
  r=3    1    1    2    4   ← 답
```

첫 행/첫 열을 무조건 1 로 채우면, 첫 행에 웅덩이가 있을 때 틀립니다. 패딩 + `dp[1][1] = 1` 로 시작하세요.

### 두 문자열 DP — LCS 와 Edit Distance

```
LCS("abcde", "ace")                         Edit Distance("horse", "ros")
같으면 ↖ + 1, 다르면 max(↑, ←)               같으면 ↖, 다르면 1 + min(↖교체, ↑삭제, ←삽입)

        ""  a  c  e                                 ""  r  o  s
   ""    0  0  0  0                            ""    0  1  2  3
   a     0  1  1  1                            h     1  1  2  3
   b     0  1  1  1                            o     2  2  1  2
   c     0  1  2  2                            r     3  2  2  2
   d     0  1  2  2                            s     4  3  3  2
   e     0  1  2  3  ← 답                       e     5  4  4  3  ← 답
```

- 0행·0열 = 빈 문자열과의 관계 (LCS 는 0, 편집 거리는 길이만큼 삽입/삭제)
- 표의 크기는 (n+1) × (m+1). 인덱스는 `text1[i-1]` 처럼 한 칸 밀려 있다는 점에 주의

### 배낭(knapsack) 계열 — 루프 방향이 의미를 바꾼다

| 종류 | 각 물건 사용 | 1차원 루프 | 대표 문제 |
|---|---|---|---|
| 0/1 배낭 (최대 가치) | 최대 1번 | 물건 바깥, 용량 **역순** `for w in range(W, wt-1, -1)` | knapsack-01, BOJ 12865 |
| 0/1 부분집합 합 (가능 여부/개수) | 최대 1번 | 물건 바깥, 합 **역순** | Partition Equal Subset Sum, Target Sum |
| 완전 배낭 (최소 개수) | 무제한 | 금액 정순 (루프 순서 무관) | Coin Change |
| 완전 배낭 (조합 개수) | 무제한 | **동전 바깥**, 금액 **정순** | Coin Change II |
| 순열 개수 | 무제한, 순서 구분 | **금액 바깥**, 동전 안쪽 | Combination Sum IV (LeetCode 377) |

왜 역순인가? 1차원 배열에서 `dp[w - wt]` 는 "이번 물건을 아직 안 넣은 상태" 여야 합니다.

```
0/1 배낭, 물건 (무게 2, 가치 3), 용량 6

정순(틀림):  w=2: dp[2] = dp[0]+3 = 3
            w=4: dp[4] = dp[2]+3 = 6   ← 방금 갱신한 dp[2] 를 또 씀 = 같은 물건 2번!
역순(맞음):  w=6 → 2 순서로 돌면 dp[w-2] 는 아직 갱신 전(이전 행) 값
```

### 상태 기계 DP — 주식 매매 + 쿨다운

```
              매수 (-p)            매도 (+p)
   ┌──────┐  ─────────▶  ┌──────┐  ─────────▶  ┌──────┐
   │ rest │              │ hold │              │ sold │
   └──────┘  ◀───────────────────────────────  └──────┘
    ↺ 대기                ↺ 보유 유지      다음 날 rest 로 (쿨다운)

hold' = max(hold, rest - p)      sold' = hold + p      rest' = max(rest, sold)
```

"날짜 × 상태" 의 2차원 표지만, 날짜 축은 어제만 보므로 상태 변수 몇 개로 줄어듭니다.

### 구간 DP (interval DP) 맛보기

- 상태가 `dp[l][r]` = 구간 [l, r] 에 대한 답. **짧은 구간부터** 채웁니다.
- 예: 최장 팰린드롬 부분 수열, 행렬 곱셈 순서, 풍선 터뜨리기(LeetCode 312), 파일 합치기(BOJ 11066)
- 전형적 점화식: `dp[l][r] = min(dp[l][k] + dp[k+1][r] + cost(l, r) for k in range(l, r))` → O(n^3)

```python
for length in range(2, n + 1):          # 구간 길이 순서 (짧은 것부터)
    for l in range(0, n - length + 1):
        r = l + length - 1
        dp[l][r] = min(dp[l][k] + dp[k + 1][r] for k in range(l, r)) + cost(l, r)
```

## 코드 템플릿

### 1) 격자 DP (패딩 + 장애물 + mod)

```python
MOD = 1_000_000_007

def grid_paths(m, n, blocked):            # blocked: {(r, c)} 1-indexed
    dp = [[0] * (n + 1) for _ in range(m + 1)]
    dp[1][1] = 1
    for r in range(1, m + 1):
        for c in range(1, n + 1):
            if (r, c) == (1, 1):
                continue
            if (r, c) in blocked:
                dp[r][c] = 0
            else:
                dp[r][c] = (dp[r - 1][c] + dp[r][c - 1]) % MOD
    return dp[m][n]
```

### 2) 두 문자열 DP (LCS / 편집 거리 공통 뼈대)

```python
def lcs(a, b):
    n, m = len(a), len(b)
    dp = [[0] * (m + 1) for _ in range(n + 1)]   # 0행·0열 = 빈 문자열
    for i in range(1, n + 1):
        for j in range(1, m + 1):
            if a[i - 1] == b[j - 1]:
                dp[i][j] = dp[i - 1][j - 1] + 1            # ↖
            else:
                dp[i][j] = max(dp[i - 1][j], dp[i][j - 1])  # ↑, ←
    return dp[n][m]
```

### 3) 0/1 배낭 — 2차원과 1차원

```python
def knapsack_2d(weights, values, W):
    n = len(weights)
    dp = [[0] * (W + 1) for _ in range(n + 1)]
    for i in range(1, n + 1):
        wt, val = weights[i - 1], values[i - 1]
        for w in range(W + 1):
            dp[i][w] = dp[i - 1][w]                                  # 안 넣음
            if w >= wt:
                dp[i][w] = max(dp[i][w], dp[i - 1][w - wt] + val)   # 넣음
    return dp[n][W]

def knapsack_1d(weights, values, W):
    dp = [0] * (W + 1)
    for wt, val in zip(weights, values):
        for w in range(W, wt - 1, -1):        # 0/1 → 역순 (완전 배낭이면 정순)
            dp[w] = max(dp[w], dp[w - wt] + val)
    return dp[W]
```

### 4) 상태 기계 DP

```python
def max_profit_cooldown(prices):
    hold, sold, rest = float("-inf"), 0, 0
    for p in prices:
        hold, sold, rest = max(hold, rest - p), hold + p, max(rest, sold)  # 동시 대입!
    return max(sold, rest)
```

### 5) DAG 위의 DP — 메모 DFS

```python
import sys
from functools import lru_cache
sys.setrecursionlimit(10**6)

def longest_increasing_path(matrix):
    R, C = len(matrix), len(matrix[0])

    @lru_cache(maxsize=None)
    def dfs(r, c):                         # (r, c) 에서 시작하는 최장 길이
        best = 1
        for nr, nc in ((r+1, c), (r-1, c), (r, c+1), (r, c-1)):
            if 0 <= nr < R and 0 <= nc < C and matrix[nr][nc] > matrix[r][c]:
                best = max(best, 1 + dfs(nr, nc))
        return best

    return max(dfs(r, c) for r in range(R) for c in range(C))
```

경로가 아주 길어질 수 있으면 "값 내림차순 정렬 후 반복문" 으로 같은 DP 를 재귀 없이 계산합니다.

## 시간 · 공간 복잡도

| 문제 | 시간 | 공간 | 공간 최적화 |
|---|---|---|---|
| Unique Paths / 등굣길 | O(R × C) | O(R × C) | 한 행 O(C) |
| 정수 삼각형 | O(h^2) | O(h) | 아래 → 위 한 줄 |
| LCS / Edit Distance | O(n × m) | O(n × m) | 두 행 O(m) (복원 필요하면 전체 표) |

| Target Sum | O(n × P) | O(P) | P = (total + target) / 2 |
| 주식 + 쿨다운 | O(n) | O(1) | 상태 변수 3개 |
| 최장 증가 경로 | O(R × C) | O(R × C) | — |
| 구간 DP | 보통 O(n^3) | O(n^2) | — |

## 자주 하는 실수

- [ ] **좌표 순서 착각**: 프로그래머스 '등굣길' 은 m = 가로(열), n = 세로(행), puddles = [x, y]. 행/열을 뒤집어 읽으면 오답.
- [ ] **첫 행/첫 열을 1 로 채우기**: 장애물이 있으면 그 뒤는 0. 패딩 배열 + 시작점 1 로 처리하세요.
- [ ] **mod 를 마지막에 한 번만**: 중간 값이 거대해져 느려집니다. 더할 때마다 `% MOD`.
- [ ] **`[[0] * m] * n`** 으로 2차원 배열 생성 → 모든 행이 같은 리스트를 공유! `[[0] * m for _ in range(n)]`.
- [ ] **0/1 배낭을 정순 루프로** → 물건을 여러 번 넣음. 완전 배낭은 반대로 정순이어야 함.
- [ ] **조합 vs 순열 루프 순서 혼동**: Coin Change II 는 동전이 바깥 루프.
- [ ] **(n+1) × (m+1) 표에서 인덱스 밀림**: `dp[i][j]` 는 `a[i-1]`, `b[j-1]` 을 봅니다.
- [ ] **상태 기계 갱신 순서 버그**: hold 를 먼저 바꾼 뒤 그 값으로 sold 를 계산하면 같은 날 사고파는 셈. 동시 대입 사용.
- [ ] **메모 DFS 의 재귀 한도**: 깊이가 1,000 을 넘을 수 있으면 `sys.setrecursionlimit` 또는 반복문으로.
- [ ] **두 행 최적화 후 복원 불가**: 실제 LCS 문자열/편집 과정을 출력해야 하면 전체 표를 유지하세요.

## 영어로 설명하기 (미국 면접용)

- "I'll define `dp[i][j]` as the length of the longest common subsequence of the first `i` characters of `text1` and the first `j` characters of `text2`."
- "If the last characters match, I extend the diagonal value by one; otherwise I take the max of dropping a character from either string — the cell above or the cell to the left."
- "Since each row only depends on the previous row, I can reduce the space from O(n·m) to O(m) by keeping two rows."
- "For 0/1 knapsack in one dimension, I iterate the capacity in reverse so that each item is used at most once; iterating forward would turn it into the unbounded version."
- "The moves only go to strictly larger values, so the graph is a DAG — there are no cycles, which means I can memoize the DFS result for each cell without a visited set."

## 체크리스트

- [ ] 두 문자열 문제를 보면 `dp[i][j]` = 두 접두사 로 상태를 바로 정의할 수 있다
- [ ] LCS 와 편집 거리 표를 손으로 채우고, 각 칸이 ↖ ↑ ← 중 어디서 왔는지 설명할 수 있다
- [ ] 격자 DP 에서 장애물·패딩·mod 처리를 실수 없이 할 수 있다
- [ ] 0/1 배낭을 2차원으로 쓰고, 1차원 역순 루프로 줄이는 이유를 설명할 수 있다
- [ ] 조합 개수(동전 바깥)와 순열 개수(금액 바깥)의 루프 순서 차이를 예시로 보일 수 있다
- [ ] 상태 기계 DP 의 상태와 전이를 그림으로 그리고 동시 대입으로 구현할 수 있다
- [ ] 사이클 없는 그래프(DAG)에서 메모 DFS 가 왜 성립하는지 설명할 수 있다
- [ ] 구간 DP 는 "짧은 구간부터" 채운다는 계산 순서를 안다
