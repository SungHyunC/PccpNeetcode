# PCCP 시험 가이드

> 프로그래머스 코딩전문역량인증(PCCP, Programmers Certified Coding Professional) 준비 전략.
> 시험 규정은 바뀔 수 있으니 응시 전에 [프로그래머스 공식 안내](https://certi.programmers.co.kr/)를 꼭 확인하세요.

## 시험 형식 (2026년 기준 공개 정보)

| 항목 | 내용 |
|---|---|
| 문항 | 코드 작성 **4문제** |
| 시간 | **120분** |
| 점수 | **1,000점** 만점, **400점 이상 합격** |
| 등급 | 점수에 따라 **Lv.1 ~ Lv.5** (점수가 높을수록 높은 등급) |
| 언어 | Python, JavaScript, Java, C, C++, C# 중 1개 선택 |
| 유효기간 | 2년 |
| 환경 | 온라인 원격 감독, 프로그래머스 웹 에디터, `def solution(...)` 완성형 |

- 문제마다 **정확성 테스트**와 **효율성 테스트**가 있을 수 있습니다. 부분 점수가 있으므로 완벽하지 않아도 제출합니다.
- 프로그래머스 코딩테스트 연습에서 **"PCCP 기출문제"** 로 검색하면 공개된 기출을 풀 수 있습니다 (예: 붕대 감기, 석유 시추, 퍼즐 게임 챌린지). 시험 직전 2주는 기출을 시간 재고 푸세요.
- 난이도는 대략 프로그래머스 Lv.1 ~ Lv.3 수준이 섞여 나옵니다. 1~2번은 구현/자료구조, 3~4번은 그래프·DP·이분 탐색 같은 알고리즘 문제가 나오는 경우가 많습니다.

## 120분 시간 전략

```
0:00 ─ 0:10  4문제 모두 읽기. 쉬운 순서 정하기 (번호 순서 ≠ 난이도 순서일 수 있음)
0:10 ─ 0:40  가장 쉬운 문제 2개 완벽하게 (정확성 + 효율성)
0:40 ─ 1:30  세 번째 문제. 막히면 브루트포스로라도 정확성 점수 확보
1:30 ─ 1:55  네 번째 문제 부분 점수 노리기 / 앞 문제 효율성 개선
1:55 ─ 2:00  모든 문제 최종 제출 확인
```

- **부분 점수 전략**: 효율성이 안 나와도 정확성 테스트를 맞히면 점수가 나옵니다. 정답 풀이가 떠오르지 않으면 브루트포스를 먼저 제출하세요.
- **제출 전에 직접 테스트 케이스 추가**: 빈 입력, 원소 1개, 최댓값, 중복, 음수.
- 한 문제에 40분 이상 막히면 다른 문제로 넘어갔다가 돌아옵니다.

## 문제 읽는 법 (구현 문제에서 특히 중요)

1. 제한사항부터 읽고 목표 복잡도 정하기 ([01-complexity](01-complexity.md))
2. 입력 → 출력을 한 문장으로 요약
3. 조건을 번호 매겨 주석으로 옮겨 적기
4. 예제를 손으로 따라가며 조건 해석 확인
5. 코드 작성 → 예제 실행 → 엣지 케이스 추가

## 파이썬 응시 팁

- `sys.setrecursionlimit(10**6)` 은 DFS 를 쓴다면 습관처럼 맨 위에.
- 큐는 반드시 `collections.deque`.
- 2차원 리스트는 `[[0] * m for _ in range(n)]`.
- 시간 변환은 분 단위 정수로: `h, m = map(int, t.split(':')); total = h * 60 + m`
- 올림 나눗셈은 `-(-a // b)` 또는 `math.ceil(a / b)` (큰 수에서는 앞의 것이 안전)
- 프로그래머스 에디터의 "코드 실행"은 예제만 돌립니다. 직접 "테스트 케이스 추가"를 활용하세요.

## 이 저장소로 실전 연습하기

```bash
python practice.py mock start --mode pccp   # 4문제(Easy, Medium, Medium, Hard) 120분 타이머
python practice.py mock status              # 남은 시간
python practice.py mock submit              # 정확성 80% + 효율성 20% 비율로 1000점 만점 채점
```

모의고사 점수 계산은 실제 PCCP 배점과 다른 근사치입니다. 실전 감각(시간 배분, 부분 점수)을 익히는 용도로 쓰세요.
